Reference 02

Godot 小游戏发布检查表

功能

  • 首次启动与重复启动
  • 所有输入动作与边界
  • 暂停、恢复、结束、重开
  • 存档缺失、正常、损坏

场景

  • 根节点无意外 Transform
  • 实例无意外属性覆盖
  • Remote 节点数稳定
  • 信号连接无断链

代码

  • 无解析错误与警告
  • 无调试 print、breakpoint、临时代码
  • 状态副作用只有一个入口
  • 导出依赖已赋值且有明确错误信息

表现

  • 不同窗口尺寸下 UI 可读
  • 音量合理，无削波与重复播放
  • 动画结束状态稳定
  • Profiler 无明显异常增长

发布

  • 主场景正确
  • 图标与产品名称正确
  • Debug 与 Release 都测试
  • 在干净目录或另一台设备验证
