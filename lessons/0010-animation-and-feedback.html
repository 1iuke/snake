Lesson 10 · 约 35 分钟

让游戏对玩家作出回应

这一课的胜利条件：Food 使用 AnimationPlayer 循环呼吸，ScoreLabel 使用 Tween 在得分时弹跳，并理解什么时候选择哪一种动画工具。

1. 两种动画工具，两类问题

AnimationPlayer
Tween
编辑器时间轴与关键帧
vs
代码创建起点、终点与时长
可反复预览和复用
vs
动态目标和一次性反馈
呼吸、角色动作、过场
vs
数值弹跳、淡入、移动到动态位置

二者都会插值属性。选择标准不是“哪个更高级”，而是动画数据更适合由时间轴编辑，还是由运行时上下文决定。

2. 用 AnimationPlayer 制作 Food 呼吸

  1. 打开 food.tscn。
  2. 选中根节点 Food，添加子节点 AnimationPlayer。
  3. 选中 AnimationPlayer，底部动画面板中新建动画，命名 pulse。
  4. 动画长度设为 0.9 秒，并启用循环。

插入 Scale 关键帧

  1. 将时间线移到 0.0，选中 Food，把 Scale 设为 (1, 1)，点击 Scale 旁的钥匙插入关键帧。
  2. 移到 0.45，把 Scale 设为 (1.15, 1.15)，插入关键帧。
  3. 移到 0.9，恢复 Scale (1, 1)，插入关键帧。
  4. 在 AnimationPlayer 的动画列表中把 pulse 设为 Autoplay。

运行游戏后，食物应围绕自身原点持续缩放。由于 food.gd 把圆心画在 Vector2.ZERO，缩放中心天然正确。

常见错误：AnimationPlayer 应是 Food 的子节点，不要把 Food 放在 AnimationPlayer 下。AnimationPlayer 继承 Node，没有 2D Transform，不应充当变换层级的中间节点。

3. 用 Tween 制作分数弹跳

在 hud.gd 的成员区域加入：

var score_tween: Tween

把分数回调扩展为：

func _on_snake_game_score_changed(
    new_score: int,
    new_high_score: int
) -> void:
    score_label.text = "SCORE  %04d" % new_score
    best_label.text = "BEST  %04d" % new_high_score

    if score_tween:
        score_tween.kill()

    score_label.pivot_offset = score_label.size / 2.0
    score_label.scale = Vector2.ONE
    score_tween = create_tween()
    score_tween.tween_property(
        score_label,
        "scale",
        Vector2(1.25, 1.25),
        0.08
    ).set_trans(Tween.TRANS_BACK).set_ease(Tween.EASE_OUT)
    score_tween.tween_property(
        score_label,
        "scale",
        Vector2.ONE,
        0.18
    ).set_trans(Tween.TRANS_SINE).set_ease(Tween.EASE_OUT)

4. 为什么先 kill 旧 Tween？

如果玩家连续快速得分，前一次动画可能尚未结束。多个 Tween 同时写同一个 scale 属性时，结果会互相竞争。保存引用并在重启动画前 kill()，可以确保一次只有一个作者控制该属性。

Tween 生命周期：不要用 Tween.new()，那样得到的 Tween 无效。使用节点的 create_tween()；Tween 不能可靠复用，每次播放都新建一个。

5. 区分布局尺寸与视觉缩放

ScoreLabel 是 HBoxContainer 的子节点。Container 根据 Label 的最小尺寸安排布局；Tween 改的是 CanvasItem 的视觉 scale，不会要求 Container 重新分配整行空间，因此适合短促反馈。

pivot_offset 设在 Label 中心，否则缩放会从左上角发生，看起来像文字向右下方跳动。

6. 可选：接入吃食物音效

准备一个很短的、允许用于项目的 .wav 或 .ogg 文件，放入项目，例如 res://audio/eat.wav。然后：

  1. 在 main.tscn 根节点下添加 AudioStreamPlayer，命名 EatSound。
  2. 把音频文件拖入它的 Stream 属性。
  3. 在 main.gd 加入：
@onready var eat_sound: AudioStreamPlayer = $EatSound

在 if ate_food: 内加入：

eat_sound.play()

UI 和全局反馈使用 AudioStreamPlayer；需要随空间距离与声像变化时，2D 游戏使用 AudioStreamPlayer2D。

7. 验收

  1. Food 出现后持续平滑呼吸，移动到新网格时动画不中断。
  2. ScoreLabel 每次得分先放大再回到 1 倍。
  3. 快速触发多次分数更新时，Label 最终稳定回到 Vector2.ONE。
  4. 暂停游戏时观察动画行为，并决定视觉反馈是否应该随游戏暂停。
  5. 若完成音效分支，吃食物时只播放一次且没有明显延迟。

8. 暂停语义

当前“暂停”只是业务变量 paused，并没有暂停整个 SceneTree。因此 AnimationPlayer 和 Tween 仍会运行。这不是引擎错误，而是产品决策。下一课会建立明确的游戏状态管理，再决定哪些节点随暂停停止。

9. 闭卷检索

问题 1：Food 呼吸为什么适合 AnimationPlayer？

它是固定、循环、需要可视化预览和反复复用的时间轴动画，关键帧比运行时代码更易编辑。

问题 2：分数弹跳为什么适合 Tween？

它由运行时得分事件即时触发，目标属性和中断行为由代码上下文决定，不需要持久时间轴。

问题 3：为什么重播前要 kill 旧 Tween？

避免多个 Tween 同时写同一属性并互相竞争，确保动画结束后状态确定。

加一分挑战

让 BestLabel 仅在创造新纪录时变成黄色并弹跳。你需要在 HUD 保存上一次最高分，比较 new_high_score 是否真正增加。注意：这是 HUD 自己的显示历史，不是全局游戏存档状态。
